# User Flows

## Flow 1 — Register and Login

1. User opens the application
2. User creates an account
3. User logs in
4. User is redirected to the dashboard

Expected result:
- User session is created successfully
- Protected pages require authentication

---

## Flow 2 — Upload and Analyze CV

1. User uploads a CV file
2. System validates the file
3. System extracts CV text
4. AI analyzes the CV
5. User receives:
   - CV score
   - strengths
   - weaknesses
   - improvement suggestions

Expected result:
- Analysis is saved to history
- User can revisit the result later

---

## Flow 3 — Compare CV With Job Description

1. User selects an uploaded CV
2. User pastes or uploads a job description
3. AI compares CV and JD
4. User receives:
   - matching score
   - matching skills
   - missing skills
   - improvement suggestions

Expected result:
- Comparison result is saved
- User understands what should improve

---

## Flow 4 — Generate Cover Letter

1. User selects a CV
2. User provides a job description
3. AI generates a tailored cover letter

Expected result:
- User can copy and edit the generated content

---

## Flow 5 — View Analysis History

1. User opens history page
2. User views previous analyses and comparisons
3. User reopens a previous result

Expected result:
- Users can track improvement over time
