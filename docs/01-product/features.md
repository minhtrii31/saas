# Features

## Current MVP Features

### Authentication

Users can register, log in, log out through client-side token removal, and access protected pages.

### CV Management

Users can upload CV files, store metadata and extracted text, view uploaded CVs, open CV detail, soft-delete CVs, and select a CV for analysis or matching.

### CV Analysis

Users can analyze a CV and receive:

- CV score
- Strengths
- Weaknesses
- Improvement suggestions

### Job Description Matching

Users can paste a job description and compare it with a selected CV.

The result includes:

- Matching score
- Matched skills
- Missing skills
- Improvement suggestions

### Cover Letter Generation

Users can generate a basic tailored cover letter from a selected CV and job description.

### History

Users can view previous CV analyses, JD comparisons, and generated cover letters in dashboard history.
