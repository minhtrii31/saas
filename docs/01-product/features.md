# Features

## MVP Features

### Authentication

Users can register, login, logout, and access protected pages.

### CV Management

Users can upload CV files, store them, view uploaded CVs, and select a CV for analysis or matching.

### CV Analysis

Users can analyze a CV and receive:

- CV score
- Strengths
- Weaknesses
- Improvement suggestions

### Job Description Matching

Users can paste or upload a job description and compare it with a selected CV.

The result includes:

- Matching score
- Matched skills
- Missing skills
- Improvement suggestions

### Cover Letter Generation

Users can generate a basic tailored cover letter from a selected CV and job description.

### History

Users can view previous CV analyses, JD comparisons, and generated cover letters.
