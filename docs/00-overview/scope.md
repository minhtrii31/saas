# Scope

## MVP v1

The first version focuses on helping users evaluate and improve their CV for job applications.

### Must Have

- User authentication
- Upload and store CV files
- Extract text from uploaded CVs
- Analyze CV quality
- Paste or upload a job description
- Compare CV against a job description
- Return matching score, matched skills, missing skills, and improvement suggestions
- Save analysis history
- Generate a basic tailored cover letter

### Not In MVP

- CV builder
- Resume templates
- Recruiter dashboard
- Public profile page
- Job tracking board
- Real-time collaboration
- Payment/subscription
- Multi-language CV generation
- Advanced analytics dashboard

## Product Principle

The MVP should validate the core value first:

Can the user understand what is weak in their CV and what to improve for a specific job?
