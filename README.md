# CV AI SaaS

AI-assisted SaaS platform for CV analysis, job description matching, improvement suggestions, and cover letter generation.

## Stack

- Next.js
- NestJS
- PostgreSQL
- Prisma
- Redis
- BullMQ
- Playwright
- Jest
- Supertest

## Architecture

- Modular monolith backend
- AI-assisted engineering workflow
- Backend TDD
- Frontend smoke/E2E testing
